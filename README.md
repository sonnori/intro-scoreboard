# Scoreboard

กระดานคะแนน 2 ทีมสำหรับถ่ายรายการเกมโชว์ ให้แต้มรายบุคคล คะแนนทีมคือผลรวมของทุกคนในทีม

ฉากหลังเป็น three.js: พื้นเวทีถูกแบ่งเป็นสองอาณาเขตตามสีทีม และ **เส้นปะทะตรงกลางจะถูกดันไปทางทีมที่ตามอยู่** ตามผลต่างคะแนน อ่านผลได้จากกล้องโดยไม่ต้องมองตัวเลข

## Deploy ขึ้น Vercel

repo นี้ deploy ขึ้น Vercel ได้เลย ตั้งค่าไว้ให้แล้วใน `vercel.json`

1. vercel.com → **Add New Project** → import repo นี้ → Deploy
2. เข้า **Storage** ของโปรเจกต์ → สร้าง **Upstash Redis** (หรือ Vercel KV) → Connect เข้ากับโปรเจกต์
3. **Settings → Environment Variables** → เพิ่ม `SCOREBOARD_PASSWORD` เป็นรหัสที่จะใช้ปลดล็อก
4. Redeploy หนึ่งครั้งให้ค่าใหม่มีผล

**ข้อ 2 ห้ามข้าม** — Vercel เขียนไฟล์ไม่ได้ ถ้าไม่มีที่เก็บข้อมูล แต่ละเครื่องจะเห็นกระดานคนละอันแยกกัน (กระดานจะขึ้นป้ายเตือนให้เองว่า "ยังไม่ได้ต่อที่เก็บข้อมูล")

**ข้อ 3 ถ้าข้าม** ใครเปิด URL ได้ก็คุมคะแนนได้ทันที เพราะไม่มีรหัสให้ตรวจ

### ต่างจากรันในสตูดิโอยังไง

| | server ในสตูดิโอ | Vercel |
|---|---|---|
| คะแนนเปลี่ยนข้ามจอ | ทันที (push ผ่าน SSE) | ประมาณ 1 วินาที (ถามเป็นรอบ) |
| ต้องมีอินเทอร์เน็ต | ไม่ต้อง แค่ WiFi วงเดียวกัน | ต้องมี |
| เข้าจากนอกสถานที่ | ไม่ได้ | ได้ |

Vercel รันโค้ดแบบ serverless คือปลุกขึ้นมาตอบทีละ request แล้วดับ จึงเปิดการเชื่อมต่อค้างเพื่อ push คะแนนสดไม่ได้ กระดานเลยเปลี่ยนไปถามทุก 1 วินาทีแทนโดยอัตโนมัติ **วันถ่ายจริงยังแนะนำให้ใช้ server ในสตูดิโอ** เพราะไวกว่าและเน็ตหลุดก็ไม่กระทบ

### รูปผู้เล่นบน Vercel

รูปใน `photos/` ต้อง commit ขึ้น repo ด้วยถึงจะไปโผล่บน Vercel — build ที่ Vercel อ่านจากโฟลเดอร์นี้

```bash
git add photos/ && git commit -m "เพิ่มรูปนักแสดง" && git push
```

repo นี้เป็น public ใครก็เปิดดูรูปที่ commit ขึ้นไปได้ ถ้าไม่ต้องการให้เปลี่ยน repo เป็น private ก่อน (Vercel ยัง deploy จาก private repo ได้ปกติ)

## รันบน server ในสตูดิโอ

```bash
npm install && npm start
```

จะ build แล้วเปิด server พร้อมพิมพ์ที่อยู่กับรหัสผ่านออกมา

```
    เครื่องนี้      http://localhost:4321
    ในสตูดิโอ      http://192.168.1.185:4321
    รหัสปลดล็อก    877048
```

เอาที่อยู่ในสตูดิโอไปเปิดที่เครื่องไหนก็ได้ในวง LAN เดียวกัน **ทุกจอเห็นคะแนนตรงกันทันที** เปิดจอสำรองกี่จอก็ได้

- **ใครเปิดก็ดูได้** แต่กดแต้มหรือแก้ตั้งค่าต้องกด "ปลดล็อก" แล้วใส่รหัสก่อน
- รหัสอยู่ที่ `server/data/password.txt` เปลี่ยนเองได้ หรือกำหนดผ่าน `SCOREBOARD_PASSWORD=1234 npm start`
- เปลี่ยนพอร์ตด้วย `PORT=8080 npm start`

**ข้อมูลอยู่ใน `server/data/db.json`** — กระดานปัจจุบันกับชุดการแข่งที่บันทึกไว้ สำรองข้อมูลคือก๊อปไฟล์นี้ (รูปอยู่ในโฟลเดอร์ `photos/` แยกต่างหาก)

### รูปผู้เล่น

ลากรูปใส่โฟลเดอร์ **`photos/`** แล้ว build — **ชื่อไฟล์คือชื่อผู้เล่น** (`ก้อง.jpg` → "ก้อง")

```bash
npm run build
```

ตอนเพิ่มผู้เล่นจะเห็นรูปที่เตรียมไว้เรียงอยู่ด้านบน กดเลือกแล้วชื่อขึ้นให้เอง ไม่ต้องพิมพ์ ถ้าอยากใช้รูปที่ไม่ได้เตรียมไว้ก็กด "เลือกรูป" browse เอาตอนนั้นได้ ทั้งสองทางจัดกรอบ (ลาก/ซูม) ได้เหมือนกัน

ไม่มีระบบอัปโหลด รูปเดินทางไปพร้อมตัวโปรแกรมตอน deploy

### ชุดการแข่ง

"ชุดการแข่ง" เก็บชื่อทีม สี ผู้เล่นและกติกาไว้ทั้งชุด กด "ใช้" ก่อนอัดเทปทีเดียวพร้อม

### ถ้า server ล่ม

หน้าเว็บจะสลับไปเก็บข้อมูลในเครื่องเองอัตโนมัติและขึ้นป้าย "ออฟไลน์" คะแนนที่กดค้างไว้ไม่หาย และยังมี `Scoreboard.html` เป็นแผนสำรองที่ไม่ต้องพึ่ง server เลย

## ใช้งานแบบไม่มี server

ดับเบิลคลิก **`Scoreboard.app`** — จบ ลากไปไว้ใน Dock หรือ Applications ได้เลย

แอปจะเปิดกระดานในหน้าต่างเปล่า ไม่มีแท็บ ไม่มีแถบที่อยู่ ไม่มีบุ๊กมาร์ก เข้ากล้องได้ทันที (ถ้าเครื่องไม่มี Chrome/Edge/Brave จะเปิดด้วยเบราว์เซอร์ปกติแทน)

ตัวหน้าเว็บล้วน ๆ อยู่ที่ **`Scoreboard.html`** ไฟล์เดียว ~0.85 MB รวมโค้ด สไตล์ และฟอนต์ไว้ข้างในหมด จะดับเบิลคลิกไฟล์นี้ตรง ๆ หรือก๊อปใส่ USB ไปเปิดเครื่องไหนก็ได้

สร้างใหม่ทั้งสองอย่างด้วยคำสั่งเดียว

```bash
npm run app
```

> ถ้าส่งแอปข้ามเครื่องด้วยอีเมลหรือดาวน์โหลด macOS จะเตือนว่าไม่รู้จักผู้พัฒนา ให้คลิกขวาที่แอป แล้วเลือก Open ครั้งเดียว (ก๊อปผ่าน USB หรือ AirDrop ไม่เจอปัญหานี้)

> ข้อควรรู้: เปิดแบบไฟล์ (`file://`) เบราว์เซอร์จะเก็บข้อมูลแยกจากตอนเปิดผ่าน localhost ผู้เล่นและกติกาที่ตั้งไว้คนละที่กัน ตั้งค่าที่เครื่องไหนก็ใช้ที่เครื่องนั้น

## เริ่มพัฒนา

```bash
npm install
```

```bash
npm run dev
```

เปิด http://localhost:5173

ต้องเปิดผ่าน dev server เท่านั้น — ดับเบิลคลิก `index.html` ตรง ๆ จะได้หน้าเปล่าเพราะเบราว์เซอร์บล็อก ES module บน `file://` (ไฟล์ที่ดับเบิลคลิกได้คือ `Scoreboard.html` เท่านั้น)

## การใช้งาน

- **ให้แต้ม** คลิกการ์ดผู้เล่น (คะแนนทีมรวมให้อัตโนมัติ)
- **ลบแต้ม** ปุ่ม − มุมซ้ายบนของการ์ด (ต้องเอาเมาส์ไปชี้ที่การ์ดก่อน)
- **แก้ไขผู้เล่น** ปุ่ม ✎ มุมขวาบนของการ์ด — เปลี่ยนชื่อ เลือกรูป หรือลบผู้เล่น
- **จัดรูป** ในหน้าเลือกรูป ลากรูปเพื่อเลื่อน เลื่อนแถบหรือหมุนสกรอลล์เพื่อซูม สิ่งที่เห็นในวงกลมคือสิ่งที่ออกอากาศ (บันทึกเป็น 512px)
- **เพิ่มผู้เล่น** การ์ดเส้นประท้ายแถวของแต่ละทีม
- **ตั้งค่า** ชื่อทีม สีทีม คะแนนที่ชนะ ดิวส์ และแต้มตัดสิน

### คีย์ลัด

| ปุ่ม | ทำอะไร |
| --- | --- |
| `Q` `W` `E` `R` `T` | ให้แต้มผู้เล่นคนที่ 1–5 ของทีมซ้าย |
| `U` `I` `O` `P` `[` | ให้แต้มผู้เล่นคนที่ 1–5 ของทีมขวา |
| `⌘Z` / `Ctrl+Z` | เลิกทำแต้มล่าสุด |
| `H` | สลับโหมดออกอากาศ |

คีย์ลัดผูกกับ *ตำแหน่งปุ่ม* ไม่ใช่ตัวอักษร สลับแป้นเป็นภาษาไทยแล้วยังใช้ได้ตามเดิม

### โหมดออกอากาศ

กดไฟ ON AIR มุมซ้ายบน (หรือ `H`) จะซ่อนปุ่มควบคุมทั้งหมดให้เหลือแต่กระดานคะแนนสำหรับเข้ากล้อง ยังคลิกให้แต้มได้ปกติ เอาเมาส์ไปชี้มุมซ้ายบนเพื่อเรียกแถบควบคุมกลับมา

## กติกา

ตั้งได้ว่ากี่แต้มชนะ และจะเปิดดิวส์หรือไม่

- **ดิวส์ปิด** ถึงแต้มเป้าหมายก่อนชนะทันที
- **ดิวส์เปิด** ต้องถึงแต้มเป้าหมาย *และ* นำห่าง 2 แต้ม
- **แต้มตัดสิน** ถึงแต้มนี้ชนะทันทีโดยไม่ต้องนำ 2 แต้ม ใส่ 0 เพื่อเล่นยาวจนกว่าจะห่าง

ป้าย "แมตช์พอยต์" ขึ้นเมื่ออีกหนึ่งแต้มจะจบเกม คำนวณจากกติกาที่ตั้งไว้จริง จึงถูกต้องทั้งกรณีดิวส์และแต้มตัดสิน

## ข้อมูล

ทุกอย่างเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ไม่มีเซิร์ฟเวอร์ ไม่ต้องต่อเน็ต (ฟอนต์ฝังมากับตัวโปรเจกต์) รูปผู้เล่นถูกครอปเป็นสี่เหลี่ยมจัตุรัส 256px ก่อนเก็บ ไฟล์จากกล้องขนาดใหญ่จึงไม่ทำให้พื้นที่เก็บเต็ม

"เริ่มใหม่ทั้งหมด" ในหน้าตั้งค่าจะลบผู้เล่นและคืนกติกาเป็นค่าเริ่มต้น

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/arena.js` | ฉาก three.js — พื้นเวที เส้นปะทะ ฝุ่นแสง คลื่นตอนได้แต้ม พลุตอนชนะ |
| `src/store.js` | สถานะ กติกา และการบันทึก (ไม่ยุ่งกับ DOM) |
| `src/main.js` | เชื่อม state กับหน้าจอ รับอินพุตทั้งหมด |
| `src/sound.js` | เสียงสั้น ๆ สร้างจาก WebAudio ไม่มีไฟล์เสียง |
| `src/api.js` | ที่เก็บข้อมูล สลับระหว่าง server กับในเครื่องอัตโนมัติ |
| `src/photos.js` | อ่านรายชื่อไฟล์ในโฟลเดอร์ `photos/` ตอน build |
| `server/index.mjs` | server เสิร์ฟหน้าเว็บ API รูป และ push คะแนนสดทุกจอ |
| `server/db.mjs` | ฐานข้อมูลไฟล์ JSON เขียนแบบ atomic |
| `server/auth.mjs` | รหัสผ่านเดียวสำหรับปลดล็อกแผงคุม |
| `scripts/bundle.mjs` | ยุบผลบิลด์เป็น `Scoreboard.html` ไฟล์เดียว พร้อมเช็คว่าไม่มีอะไรอ้างออกนอกไฟล์ |
| `scripts/make-app.mjs` | ห่อเป็น `Scoreboard.app` ของ macOS วาดไอคอนเองไม่ต้องพึ่งไฟล์ภาพ |
