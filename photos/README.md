# รูปผู้เล่น

ลากไฟล์รูปมาวางในโฟลเดอร์นี้ รองรับ `.jpg` `.jpeg` `.png` `.webp`

**ชื่อไฟล์คือชื่อผู้เล่น** — `ก้อง.jpg` จะขึ้นเป็น "ก้อง" ให้อัตโนมัติตอนเลือกรูป ไม่ต้องพิมพ์ชื่อเอง

รูปจะไปโผล่ในหน้าเลือกรูปของผู้เล่น เลือกแล้วยังจัดกรอบ (ลาก/ซูม) ได้เหมือนเดิม

## ลากรูปใส่แล้วต้องทำอะไรต่อ

```bash
npm run build
```

เบราว์เซอร์อ่านรายชื่อไฟล์ในโฟลเดอร์เองไม่ได้ ตอน build จึงต้องไปไล่ดูแล้วทำรายการไว้ให้ครั้งหนึ่ง

## ข้อแนะนำ

ครอปเป็นสี่เหลี่ยมจัตุรัสมาก่อนได้ยิ่งดี แต่ไม่จำเป็น — จัดกรอบในโปรแกรมได้อยู่แล้ว

ขนาดที่พอดีคือด้านละ 600–1000px ใหญ่กว่านี้ไม่ได้ช่วยให้ชัดขึ้นเพราะตอนบันทึกย่อเหลือ 512px แต่จะทำให้ไฟล์ที่ deploy ใหญ่ขึ้นโดยเปล่าประโยชน์
